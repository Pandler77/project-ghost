# Design System

## Product Focus

The Home screen answers:

> What do I need to do today?

The Calendar answers:

> What happened on this day?

Tools contain actions and utilities.

Settings contain configuration.

## Spacing

- XS: 4
- SM: 8
- MD: 16
- LG: 24

## Cards

- Rounded corners
- Low elevation
- 16 px internal padding
- One clear purpose per card
- No dead empty states

## Empty States

Every empty state must include:

- A short explanation
- One clear action
- No unnecessary information

## Colors

- Protocol colors remain consistent throughout the app
- Completion green is reserved for completed actions
- Colors must remain readable in light and dark modes

## Home

Default sections:

1. Today
2. Weight, when enabled
3. Upcoming
4. Recent activity

Users may later hide or reorder sections.

## Navigation

Bottom navigation:

- Home
- Protocols
- Calendar
- Tools

Settings opens from the gear icon.

## Interaction

- Repeated actions should require minimal taps
- Historical day edits must not modify future protocol schedules
- No feature should appear on Home unless it is useful to that user
